# Moodle Plugins directory content

## Description

Percentage is a Moodle activity module that lets students calculate and visualize common percentage operations directly inside a course.

It supports percentage of a value, percentage represented by a part of a total, percentage change, increases, discounts, margin, markup and profit. Results can be displayed as a proportional bar, donut chart, 10 × 10 percentage grid or before/after comparison, with automatic visualization selection when preferred.

Teachers can choose which operations are available, configure the default visualization, define decimal precision and decide whether the formula and a short explanation are displayed with the result.

Calculations run in the browser and the values entered by students are not stored as personal data.

Requirement: Moodle 4.5 or later.
